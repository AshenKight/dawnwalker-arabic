# The Blood of Dawnwalker — Arabic Localization

Official project repository for the community Arabic localization prepared by **Ashen Knight**.

The website is deployed from `public/` through GitHub Pages. Game archives are distributed only as GitHub Release assets and are intentionally excluded from Git history.

Current text audit: Steam `25129649`, reconciled against `25014996` by source identity and hash. Release 1.0.7 corrects 450 text identities; the full payload and smart installer share verified release hashes. Legal text, protected labels and unresolved fictional language are not counted as translated gameplay.
