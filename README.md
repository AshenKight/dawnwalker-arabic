# The Blood of Dawnwalker — Arabic Localization

Official project repository for the community Arabic localization prepared by **Ashen Knight**.

The website is deployed from `public/` through GitHub Pages. Game archives are distributed only as GitHub Release assets and are intentionally excluded from Git history.

Current text audit: Steam `25232147`, reconciled against `25129649` by source identity and hash. Release 1.0.8 contains no new linguistic changes; 148 dialogue assets were rebuilt from the updated game data for technical compatibility. The full payload and smart installer share verified release hashes. Legal text, protected labels and unresolved fictional language are not counted as translated gameplay.
